# Matériel de départ du TP2

## `extensions_collegue.py`

Ce fichier est le sujet de la **mission 5**. Copie-le dans ton dépôt, au même niveau
que ton code métier, et travaille dessus.

Il est autonome : il ne dépend d'aucun choix de découpage que tu feras aux missions 2
et 3. Tu peux donc t'en occuper quand tu veux.

Le contrat de la classe de base est écrit dans sa docstring. C'est ce contrat que tes
tests doivent vérifier, et c'est lui qui te dira quel sous-type ment.

## Le reste

Pour le code de départ des missions 1 à 4, tu utilises ton propre dépôt du TP1.

Si tu ne l'as pas terminé, prends `tp1/solution/`. Elle est complète, elle a 76 tests
verts et 99 % de couverture de branches.
